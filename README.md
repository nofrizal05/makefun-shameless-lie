A tiny Python program that writes the most shameless lie to `/output/entry.txt` — one line, deadpan, brazen, and obviously false: the claim that someone actually read all 47 pages of the terms and conditions, twice, for fun, and highlighted their favourite clause in three colours. Nobody has ever done that. That is the point.

## Run it

```sh
python3 main.py
```
